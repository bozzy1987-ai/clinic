# EC CLINIC — projekt demonstracyjny

Koncepcja strony dla EC CLINIC Edyty Cichor w Zawierciu. To niezależny projekt pokazowy, nie oficjalna witryna firmy.

Treści ofertowe, adres, telefon i odnośnik do rezerwacji pochodzą z publicznego profilu [Booksy](https://booksy.com/pl-pl/99158_ec-clinic-edyta-cichor_salon-kosmetyczny_12514_zawiercie), sprawdzonego we wrześniu 2026 r. Aktualne ceny, terminy i szczegóły usług należy zawsze sprawdzić tam przed wizytą. Portret w projekcie został wygenerowany na potrzeby koncepcji i jest zdjęciem ilustracyjnym.

Zdjęcia zabiegów są ilustracyjne, nie pokazują personelu, wnętrza ani wyposażenia EC CLINIC. Pochodzą z Pexels i zostały użyte zgodnie z [licencją Pexels](https://www.pexels.com/license/): [twarz](https://www.pexels.com/photo/facial-treatment-at-a-skincare-clinic-30809944/), [podologia](https://www.pexels.com/photo/close-up-of-professional-pedicure-session-34930127/), [depilacja laserowa](https://www.pexels.com/photo/laser-hair-removal-procedure-in-a-clinic-35103885/), [zabiegi na ciało](https://www.pexels.com/photo/woman-receiving-body-massage-from-a-therapist-4599395/), [trychologia](https://www.pexels.com/photo/a-hairdresser-massaging-woman-head-23349902/), [laseroterapia](https://www.pexels.com/photo/person-having-a-laser-treatment-12556695/).

Uruchomienie lokalne: `npm install`, potem `npm run dev`. Wersja produkcyjna: `npm run build`.
