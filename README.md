# EC CLINIC — projekt demonstracyjny

Koncepcja strony dla EC CLINIC Edyty Cichor w Zawierciu. To niezależny projekt pokazowy, nie oficjalna witryna firmy.

Treści ofertowe, adres, telefon i odnośnik do rezerwacji pochodzą z publicznego profilu [Booksy](https://booksy.com/pl-pl/99158_ec-clinic-edyta-cichor_salon-kosmetyczny_12514_zawiercie), sprawdzonego we wrześniu 2026 r. Aktualne ceny, terminy i szczegóły usług należy zawsze sprawdzić tam przed wizytą.

Portret w sekcji głównej, zdjęcia gabinetu, zdjęcia przy kosmetologii twarzy, depilacji laserowej oraz EMS, a także otwierane po kliknięciu zdjęcia podologiczne „przed i po” pochodzą z publicznego profilu EC CLINIC w Booksy. Ich dokładne adresy źródłowe są zapisane w [PHOTO_SOURCES.md](PHOTO_SOURCES.md). To projekt demonstracyjny; przed oficjalną publikacją wykorzystanie zdjęć i zgody osób widocznych na nich należy potwierdzić z EC CLINIC.

Zdjęcia na kartach podologii, trychologii i laseroterapii są ilustracyjne i nie pokazują EC CLINIC. Pochodzą z Pexels i zostały użyte zgodnie z [licencją Pexels](https://www.pexels.com/license/): [podologia](https://www.pexels.com/photo/close-up-of-professional-pedicure-session-34930127/), [trychologia](https://www.pexels.com/photo/a-hairdresser-massaging-woman-head-23349902/), [laseroterapia](https://www.pexels.com/photo/person-having-a-laser-treatment-12556695/).

Uruchomienie lokalne: `npm install`, potem `npm run dev`. Wersja produkcyjna: `npm run build`.
