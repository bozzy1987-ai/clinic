# EC CLINIC — projekt demonstracyjny

Koncepcja strony dla EC CLINIC Edyty Cichor w Zawierciu. To niezależny projekt pokazowy, nie oficjalna witryna firmy.

Treści ofertowe, adres, telefon i odnośnik do rezerwacji pochodzą z publicznego profilu [Booksy](https://booksy.com/pl-pl/99158_ec-clinic-edyta-cichor_salon-kosmetyczny_12514_zawiercie), sprawdzonego we wrześniu 2026 r. Aktualne ceny, terminy i szczegóły usług należy zawsze sprawdzić tam przed wizytą.

Portret w sekcji głównej, zdjęcia gabinetu oraz fotografie zabiegów otwierane po kliknięciu kart twarzy, podologii, depilacji laserowej i EMS pochodzą z publicznego profilu EC CLINIC w Booksy. Ich dokładne adresy źródłowe są zapisane w [PHOTO_SOURCES.md](PHOTO_SOURCES.md). To projekt demonstracyjny; przed oficjalną publikacją wykorzystanie zdjęć i zgody osób widocznych na nich należy potwierdzić z EC CLINIC.

Zdjęcia na jedenastu kartach zabiegów są ilustracyjne i nie pokazują EC CLINIC.
